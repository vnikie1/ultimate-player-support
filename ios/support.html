Ultimate Player connects to media you already have. It ships no content of its own — you point it at a network share or media server, and it builds a browsable library with artwork, subtitles and resume positions.

Getting started

On first launch the app shows a sample library so you can look around. Those titles are placeholders — they disappear as soon as you add a real source.

  1. Open Settings → Add Movies/TV Shows.
  2. Pick the kind of source you want to connect (see the list below).
  3. Enter the host address, and a username and password if the source needs one.
  4. Save. The app scans the source and builds your library — usually a few seconds, longer for very large collections.

Ultimate Player looks for servers on your local network automatically. The first time it does this iOS asks for permission to find devices on your network — if you decline, you can still add a server by typing its address by hand, or re-enable it later in iOS Settings → Ultimate Player → Local Network.

What you can connect

Network shares

SMB (Windows shares, NAS boxes, macOS file sharing) · FTP · WebDAV

Media servers

Jellyfin · Plex — libraries, artwork and watch state come from the server, and playback progress is reported back to it.

On this device

Files already on your iPhone or iPad, including anything you have downloaded in the app for offline viewing, or imported through the Files app.

Troubleshooting

My server does not appear when I scan

  • Confirm the device and the server are on the same network. A VPN on either end will usually break discovery — try turning it off.
  • Check that local network permission is granted: iOS Settings → Ultimate Player → Local Network.
  • Automatic discovery is a convenience, not a requirement. Add the server manually with its IP address and port instead — that path does not depend on discovery working.

The share connects but no videos show up

  • Check the account you signed in with can actually read that folder.
  • Point the app at the folder that holds the media, rather than the very top of a large drive — a scan that has to walk an entire disk takes a long time.
  • Pull down on the Home screen to rescan.

A video will not play, or plays with no picture

  • Ultimate Player plays a wide range of formats, but a few exotic codecs are not supported on iOS. The player says so explicitly when it hits one.
  • Very high-bitrate files over Wi-Fi can stall. Try a wired server, move closer to the router, or download the file for offline playback first.
  • If playback stops partway through, the connection to the server most likely dropped — the player shows a Retry action.

Subtitles are missing or out of sync

  • Subtitle files sitting next to the video are picked up automatically. You can also search for subtitles from within the player.
  • If a subtitle track runs ahead or behind, adjust the delay in the player's subtitle settings.
  • Size, colour and background are in Settings → Playback.

Downloads

  • Downloads continue while the app is in the background. Manage them in Settings → Downloads, where you can pause, resume, retry or delete.
  • Downloads are Wi-Fi only by default. To allow cellular, turn on Cellular Sync & Download in Settings → General.
  • That same screen shows how much storage downloads are using, with an option to clear them all.
