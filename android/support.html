Ultimate Player connects to media you already have. It ships no content of its own — you point it at a network share or media server, and it builds a browsable library with artwork, subtitles and resume positions.

New here? The illustrated Setup & User Guide walks through connecting a source and using every screen, with a screenshot of each step.

Getting started

On first launch the app shows a sample library so you can look around, and a short walkthrough that you can dismiss at any time. Those sample titles are placeholders — they disappear as soon as you add a real source. Tapping Load a demo library connects a public Jellyfin demo server if you want to try the app properly before wiring up your own.

  1. Open Settings → Add Files.
  2. Tap Add Share and pick your server from On Your Network, or choose the kind of source you want to add by hand.
  3. Enter the address, and a username and password if the source needs one.
  4. Tap Connect & Scan. The app scans the source and builds your library — usually seconds for a media server, longer for a large network share.

What you can connect

Media servers

Jellyfin · Plex — libraries, artwork and watch state come from the server, and playback progress is reported back to it, so resume follows you between devices.

Network shares

SMB (NAS boxes, Windows shares, macOS file sharing) · FTP · NFS · WebDAV

On this device

A folder on your phone, a direct video URL, and anything you have downloaded in the app for offline playback.

Troubleshooting

My server does not appear when I scan

  • Give it a few seconds — "Searching your network…" is not a failure.
  • Confirm the phone and the server are on the same network. Mobile data can't reach your NAS, and a VPN on either end will usually break discovery.
  • Automatic discovery is a convenience, not a requirement. Add the server manually with its IP address and port instead — that path does not depend on discovery working.

The share connects but no videos show up

  • Check the account you signed in with can actually read that folder.
  • Point the app at the folder that holds the media rather than the very top of a large drive — a scan that has to walk an entire disk takes a long time.
  • The status card in Settings shows exactly what the scan found. The circular arrow on it rescans.

Titles are listed as "others"

  • "Others" means the file was found but not identified. A large share takes a few minutes to identify everything; the Home top bar shows progress while it works.
  • Files identify far more reliably when named Title (Year) for films and Show S01E02 for episodes.
  • Use Re-fetch all metadata on the source, or fix a single title by hand with Edit Metadata. Unidentified files still play.

A video will not play, or stalls partway

  • The app bundles extra decoders for audio Android often lacks (Dolby AC-3/E-AC-3, DTS), but some combinations still need the server to transcode. On Jellyfin or Plex, change Quality in the player's settings to have the server do the work.
  • Very high-bitrate 4K over Wi-Fi can outrun the connection. Lower the quality, move closer to the router, or download the title for offline playback.
  • If playback stops partway through, the connection to the server most likely dropped — the player offers a Retry.

Subtitles are missing or out of sync

  • Subtitles inside the file and sidecar .srt files beside it are picked up automatically.
  • If there are none, use Download subtitles… in the player's settings to search online.
  • Size, colour and background are in Settings → Playback → Subtitles.

Downloads

  • Download a title from its detail page; manage everything in Settings → Downloads.
  • Downloads are Wi-Fi only by default. To allow mobile data, turn on Cellular Sync & Download in Settings → General.
  • Downloaded titles play with no network at all, and appear under the Downloaded tab in Library.

Android TV

The same app runs on Android TV and Google TV with a dedicated 10-foot interface for the remote. Sources are added the same way, and Jellyfin's Quick Connect lets you sign in by approving a code on another device instead of typing a password with the D-pad.
